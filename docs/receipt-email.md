# Email receipts

The installation owner opens Settings, Receipt email and saves the dedicated receipts address with storage consent. In the Cloudflare account that hosts this installation, enable Email Routing for that address's domain and add an exact-address rule whose action delivers to this installation's deployed Worker. The production Worker exports its native `email` handler. Saving an address in Coaster does not configure or verify the external rule. Do not route a personal mailbox or a domain-wide catch-all to this intake.

A member forwards from their registered address. Additional sender addresses require the member's own native session and a one-time code delivered to the additional address. A delegate cannot confirm an alias. Removing an alias or deactivating the member prevents future assignment; confirmation never releases older held messages.

Supported image and PDF MIME parts become private inbox originals, including inline images. HTML is reduced to inert text and rendered into a paginated PDF; scripts, CSS and remote images do not run or load. When an email contains both HTML and supported attachments, both are retained as receipts. Plain body text is rendered when there is no supported attachment. No provider-supplied field is applied to an expense during intake. Existing explicit receipt reading, source regions and the one-question confirmation service handle disagreement with an attached card charge. An ignored question changes no expense value.

The exact original message bytes, including its headers, are retained once with a SHA-256 digest. Inbox originals link to that private source. Only the employee and their live delegates can download assigned source mail. Unknown senders, unsupported content and failed parsing are held for the owner without assignment. Held messages have no release action. Raw mail is downloaded as an attachment and never rendered as active HTML. Replayed identical messages produce no extra receipt. Maximum message size is 25 MB; receipt files retain the existing 10 MB maximum.

Adopted custody default awaiting ct: the trusted Cloudflare email event supplies the envelope sender; there is no public HTTP intake. Owner consent enables one exact destination, alias proof grants only future assignment, source mail stays private append-only financial evidence, and financial erasure removes alias grants and replaces stored identity indexes while preserving the original evidence bytes. This round does not claim hosted routing proof, independent comparison of merchant-body fields against a separate attachment reading, or support for answering APPROVE-006 comments from email replies.

Cloudflare setup: [Route emails](https://developers.cloudflare.com/email-service/get-started/route-emails/) and [Worker email events](https://developers.cloudflare.com/email-service/api/route-emails/email-handler/).
